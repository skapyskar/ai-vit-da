Project

The application accepts initial and goal states, or generates a solvable puzzle. DLS searches up to the selected depth limit. The page shows search steps, the frontier, expanded visits, the solution path and statistics.

The comparison page runs DLS at different limits. Only the assigned algorithm is implemented.

Technologies: HTML5, CSS3, JavaScript and Bootstrap.
